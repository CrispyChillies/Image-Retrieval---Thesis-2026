🖼️ Bước 0 – Chuẩn bị ảnh đầu vào
Mô phỏng hai ảnh X-quang ngực độ phân giải 224×224 (chuẩn ImageNet cho DenseNet121). Ảnh truy vấn có một tổn thương nhỏ (nodule) tại thùy phổi phải trên. Ảnh truy hồi là ảnh tương tự cùng nhóm bệnh, không có tổn thương rõ ràng. SimAtt concatenate cả hai thành một batch duy nhất trước khi đẩy qua backbone.
Query x_q
shape : [1, 3, 224, 224] norm : ImageNet mean/std label : Nodule (right lung)
Retrieved x_p (positive)
shape : [1, 3, 224, 224] norm : ImageNet mean/std label : Same class (lung)
SimAtt concatenation
x = cat([x_q, x_p]) → shape [2, 3, 224, 224]
Negative x_n (Triplet mode)
shape : [1, 3, 224, 224] label : Different class → x = cat([x_q, x_p, x_n]) → [3, 3, 224, 224]
Forward hook được đăng ký trên feature_module (Dense Block 4) trước khi chạy forward pass.
🏗️ Bước 1 – Kiến trúc DenseNet121
DenseNet121 sử dụng Dense Connections: mỗi layer kết nối trực tiếp đến tất cả layer phía sau trong cùng Dense Block. Backbone xử lý batch [2,3,224,224] và SimAtt hook vào output cuối của Dense Block 4 – feature map [2,1024,7,7] – trước khi Global Average Pooling.
SimAtt hook code
feats = [] def hook_fn(m, inp, out): feats.append(out) handle = feature_module\ .register_forward_hook(hook_fn) _ = model(x_batch) handle.remove()

Tính scalar score s = |x| @ w cho từng ảnh trong batch. Sau đó gọi torch.autograd.grad(unbind(s), feats) để lấy gradient của score theo feature map.

🎯 Bước 6 – Class Activation Map (CAM)
Weighted sum của feature maps theo channel weights, áp ReLU, rồi upsample bilinear lên 224×224. Map 7×7 raw được hiển thị bên dưới.
