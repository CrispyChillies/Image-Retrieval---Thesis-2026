SimAtt

Similarity-Attention Saliency – phương pháp giải thích truy vấn ảnh bằng GradCAM hướng metric

Image Retrieval Saliency / XAI GradCAM-style Metric Learning

🔭 Bức tranh toàn cảnh

SimAtt (Similarity Attention) là phương pháp sinh saliency map cho bài toán truy vấn ảnh dựa trên độ tương đồng embedding. Thay vì hỏi "vùng nào khiến mô hình phân loại đúng?" như GradCAM truyền thống, SimAtt hỏi:

"Vùng nào trên ảnh truy vấn / ảnh kết quả quyết định sự giống nhau hoặc khác nhau giữa chúng trong không gian embedding?"

Phương pháp có thể hoạt động theo cấu hình Siamese (query + positive) hoặc Triplet (query + positive + negative), và sinh ra saliency map trên tất cả các ảnh đầu vào.

Các ảnh được concatenate thành một batch trước khi đẩy qua backbone, đảm bảo feature map và embedding đều có cùng gradient context.

🔢 Các bước chi tiết

  1. Concatenate đầu vào. Tất cả ảnh được ghép thành một batch duy nhất theo chiều batch dimension: x = [x_q ; x_p ; x_n] (tùy cấu hình). Batch duy nhất này được đẩy qua backbone một lần để tiết kiệm chi phí tính toán.

  2. Thu thập feature map trung gian và embedding đầu ra. SimAtt sử dụng một trong hai cơ chế:

    • ModelOutputs extractor – hook vào module con cụ thể (target_layers).
    • Forward hook – khi target_layers=None, hook thẳng vào feature_module.

    Kết quả: A (list feature map), x (embedding cuối).

  3. Tính vector trọng số w từ không gian embedding. Đây là điểm đặc trưng cốt lõi của SimAtt.

    x_norm = L2_normalize(x) # shape [B_total, D] w = |x_norm[0] - x_norm[1:]| # khoảng cách tuyệt đối từng chiều # giữa query và mỗi ảnh còn lại if x_p is not None: w[0] = 1 - w[0] # đảo ngược chiều positive: # chiều nào query ≈ positive → trọng số cao w = ∏ w[i] (element-wise product qua tất cả i)

    Intuition: w[d] cao nghĩa là chiều d của embedding phân biệt mạnh query vs. negative (và đồng thời gần với positive). Đây là vector "discriminative dimension".

  4. Tính điểm số mẫu (sample score) s.

    s = |x| @ w # shape [B_total] # chiều embedding nào lớn + có trọng số cao → điểm cao

    Mỗi ảnh trong batch nhận một scalar score. Score cao nghĩa là embedding của ảnh đó "kích hoạt mạnh" các chiều phân biệt nhất.

  5. Backprop gradient của s về feature map. Giống GradCAM, ta tính gradient của score theo feature map cuối (không cần zero_grad vì chạy trong context gradient bình thường):

    feats = A[-1] # [B_total, C, h, w] grads = ∂s / ∂feats # [B_total, C, h, w] weights = mean(grads, dim=(H, W)) # [B_total, C] – global average pooling

  6. Tính Class Activation Map (CAM) M.

    M = weights ⊗ feats # weighted sum over channels = Σ_c weights[c] * feats[c, :, :] # → [B_total, 1, h, w] M = ReLU(M) # giữ lại đóng góp dương M = upsample(M, (H,W)) # bilinear nội suy về kích thước ảnh gốc M = M.squeeze(1) # → [B_total, H, W]

  7. Trả về saliency map cho tất cả ảnh đầu vào. Output có shape [B_total, H, W] trong đó: M[0] là map của query, M[1] của positive, M[2] của negative.

💻 Code thực tế (rút gọn, có chú thích)

def forward(self, x_q, x_p=None, x_n=None):
    _, _, H, W = x_q.size()

    # 1. Concatenate tất cả ảnh thành một batch
    x = x_q
    if x_p is not None: x = torch.cat((x, x_p))
    if x_n is not None: x = torch.cat((x, x_n))

    # 2. Forward pass – thu feature map + embedding
    if self.use_forward_hook:
        A = []
        handle = self.feature_module.register_forward_hook(hook_fn)
        x = self.model(x)
        handle.remove()
    else:
        A, x = self.extractor(x)

    # 3. Tính trọng số w từ khoảng cách embedding
    x_norm = nn.functional.normalize(x.detach(), dim=1)
    w = torch.abs(x_norm[0] - x_norm[1:])   # [N-1, D]
    if x_p is not None:
        w[0] = 1 - w[0]              # đảo chiều positive
    w = torch.prod(w, dim=0)          # [D] – product qua tất cả ảnh

    # 4. Điểm số mẫu: s = |embedding| · w
    s = torch.matmul(torch.abs(x), w)   # [B_total]

    # 5. Gradient của s w.r.t feature map
    feats = A[-1]
    grads = torch.autograd.grad(torch.unbind(s), feats)[0]

    with torch.no_grad():
        # 6. Global Average Pooling trên gradient
        weights = torch.mean(grads, dim=(2, 3))   # [B, C]

        # 7. Weighted sum → CAM
        M = torch.bmm(weights.unsqueeze(1),
                        feats.reshape(feats.shape[0], feats.shape[1], -1))
        M = M.reshape(feats.shape[0], 1, feats.shape[2], feats.shape[3])

        # 8. ReLU + upsample
        M = M.clamp(min=0)
        M = nn.functional.interpolate(M, size=(H, W), mode='bilinear')
        M = M.squeeze(1)   # [B_total, H, W]

    return M

Nguồn "nhãn" Class label rời rạc Cặp / bộ ảnh tương đồng (Siamese / Triplet)

Output 1 map / ảnh 1 map / ảnh cho tất cả ảnh trong batch
Cần nhãn lớp? Có Không – chỉ cần cặp tương đồng

🧮 Trực giác toán học

Gọi embedding query là e_q, positive là e_p, negative là e_n. Sau L2-normalize:

w_d = |e_q[d] - e_p[d]| (gần nhau → nhỏ → sau đảo: 1 - nhỏ = lớn) × |e_q[d] - e_n[d]| (xa nhau → lớn) ⇒ w_d lớn khi chiều d ĐỒng thời: • gần query–positive (tương đồng thực sự) • xa query–negative (phân biệt rõ) s_i = Σ_d |e_i[d]| · w_d ⇒ s_i lớn khi ảnh i kích hoạt mạnh các chiều discriminative

Gradient ∂s/∂feats sau đó cho biết vùng không gian nào trong feature map đóng góp nhiều nhất vào các chiều discriminative đó.

Lưu ý: SimAtt không cần threshold khoảng cách hay negative mining ở thời điểm inference – toàn bộ logic phân biệt nằm trong vector w được tính on-the-fly từ embedding.

🛠️ Các chế độ sử dụng

Cấu hìnhĐầu vàoTác dụng của w
Siamese (+) query, positive Vùng giống nhau giữa cặp ảnh (w đảo ngược → chiều gần = cao)
Siamese (−) query, negative Vùng khác nhau giữa cặp ảnh
Triplet query, positive, negative Vùng phân biệt pos vs. neg theo quan điểm của query
Quadruplet query, positive, neg1, neg2 Tổng hợp nhiều chiều phân biệt hơn (product tất cả w)
Feature extraction: nếu target_layers=None, SimAtt dùng forward hook thẳng trên feature_module (hỗ trợ nested backbone như ViT, DenseNet…). Nếu truyền target_layers cụ thể, dùng ModelOutputs extractor.

⚠️ Hạn chế cần lưu ý

  • Cần gradient thực sự: SimAtt phải gọi torch.autograd.grad nên không chạy trong torch.no_grad() ở bước tính score. Feature map phải có requires_grad=True.
  • Phụ thuộc vào chất lượng embedding: Nếu metric learning chưa hội tụ, vector w không phản ánh đúng các chiều discriminative.
  • Spatial resolution thấp: Như GradCAM, map được upsample từ feature map nhỏ → có thể bị mờ với ảnh độ phân giải cao. Các phương pháp như GradCAM++ hoặc Score-CAM có thể cải thiện điều này.
  • Product w dễ bị triệt tiêu: Nếu nhiều ảnh negative có embedding gần query ở những chiều khác nhau, product của tất cả |w_i| dễ ra vector gần 0.
